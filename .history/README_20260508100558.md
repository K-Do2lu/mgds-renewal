# MG데이터시스템 웹 (mg-prj)

## 이 프로젝트는

**MG데이터시스템**을 소개하는 반응형 웹 프론트입니다. Vue 3 · Vite · Element Plus로 구성되어 있으며, 회사/사업/공지/채용 등 정보를 페이지로 제공하고, 사내·파트너용 **디자인·컴포넌트 가이드**는 `/guide`에서 확인합니다.

### 페이지 구성(라우트 대표)

| 구간 | 설명 |
|------|------|
| `/` | 메인(히어로, 사업 요약 등) |
| `/company`, `/business`, `/notice`, `/recruit` | 섹션별 하위 페이지(서브 네비) |
| `/guide` | 색상·아이콘·폼·레이아웃 스타일 가이드(개발 서버에서 접근) |
| `/privacy`, `/terms`, `/email` | 개인정보처리방침·이용약관·이메일 무단수집 거부 |

별도 REST API 없이 정적/클라이언트 라우팅 중심이며, 외부 링크(채용 사이트, MGDshop 등)와 `public` 정적 파일(CI 다운로드 등)을 함께 사용합니다.

## 요구 사항

- Node.js 18 이상 권장

## 설치 및 실행

```bash
npm install
npm run dev
```

- **개발 서버:** `npm run dev` — 기본적으로 Vite 개발 서버 (포트는 터미널 출력 참고)
- **프로덕션 빌드:** `npm run build` — 출력 디렉터리 `dist/`
- **빌드 미리보기:** `npm run preview`

## 환경 변수

프로젝트 루트에 `.env` 또는 `.env.local`을 두고 값을 설정합니다. 예시는 [.env.example](.env.example)를 복사해 사용하세요.

| 변수 | 설명 |
|------|------|
| `VITE_APP_TITLE` | 문서 제목(`document.title`). 미설정 시 `index.html`의 기본 제목 유지 |

Vite 규칙상 클라이언트에서 쓰는 변수는 `VITE_` 접두사가 필요합니다.

## 디자인 토큰·스타일

- **팔레트·레이아웃·컴포넌트 치수:** [src/assets/scss/abstract/_variables.scss](src/assets/scss/abstract/_variables.scss)
- **반응형:** [src/assets/scss/abstract/_breakpoints.scss](src/assets/scss/abstract/_breakpoints.scss) — `$bp-tab`(920px) 이하를 “탭 이하”로 보며, 헤더 와이드 네비는 JS에서 `min-width: 921px`([src/config/layoutConstants.js](src/config/layoutConstants.js))로 맞춥니다.
- 스타일 가이드 페이지: 개발 서버에서 `/guide` — Color 탭에 팔레트·시맨틱 컬러·브레이크포인트 표가 있습니다.
- 가이드용 토큰 요약(수동 동기화): [src/config/designTokens.js](src/config/designTokens.js) — SCSS 변경 시 함께 갱신하세요.

## 설정 파일

| 경로 | 용도 |
|------|------|
| [src/config/site.js](src/config/site.js) | 사이트명, 대표 URL, 채용/MGDshop 등 외부 링크, `public` 경로 URL 헬퍼 |
| [src/config/layoutConstants.js](src/config/layoutConstants.js) | 헤더 메가메뉴·반응형 분기(px) |
| [src/config/sectionNav.js](src/config/sectionNav.js) | 헤더 1차·서브·메가 메뉴 데이터 |
| [src/config/subPageHeadings.js](src/config/subPageHeadings.js) | 섹션 페이지 타이틀 메타 |
| [src/config/familySites.js](src/config/familySites.js) | 푸터 패밀리 사이트 목록록 |

## 경로 별칭

`@/` → `src/` ([vite.config.js](vite.config.js)의 `resolve.alias`).

## 정적 자산

`public/` 아래 파일은 빌드 시 그대로 복사됩니다. `import.meta.env.BASE_URL`을 반영한 URL이 필요하면 `publicAssetUrl()` ([src/config/site.js](src/config/site.js))을 사용합니다.
